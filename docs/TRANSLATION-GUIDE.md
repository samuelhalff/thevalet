# Translation guide — FR ↔ EN

FR is the master. EN mirrors it: same facts, same sections, same FAQ count, same `translationKey`,
`order` and `delivery`; the slug is English and keyword-led (see `docs/CONTENT-GUIDE.md`).

- Write idiomatic British English, not a word-for-word rendering. Keep the calm, precise voice.
- Internal links point to the EN equivalents (`/en/services/<en-slug>/`, `/en/request/?service=<key>`,
  resort anchors `#verbier` etc. are identical in both languages).
- FR typography: spaces before : ; ? ! (the site converts them to narrow no-break spaces and
  straight apostrophes to ’ automatically).
- Terms: conciergerie privée = private concierge; intendance de résidence = residence management;
  transferts Genève–Alpes = Geneva–Alps transfers; mise à disposition = hourly / full-day hire;
  partenaires dûment autorisés = appropriately licensed partners; demande = request.
